# 🌈 الفبای رنگی

بازی آموزشی تحت وب برای یادگیری خواندن الفبای فارسی در سن اول دبستان.
معلم یا مادر دو حرف انتخاب می‌کند، کلمه نوشته و خوانده می‌شود، و کودک باید همان حرف‌ها را بسازد تا امتیاز بگیرد.

**نسخه‌ی آنلاین:** `https://ryhnhzr.github.io/alefba-rangi/`
## امکانات

- ۳۳ حرف (آ تا ی) به‌صورت جدا و رنگارنگ، هر حرف با رنگ مخصوص خودش
- حرکت‌های کوتاه (ـَ ـِ ـُ) و حرف‌های ا، و، ی برای ساختن هجا و کلمه، مثل «بَه» و «با»
- **حالت معلم/مادر:** انتخاب حرف‌ها، شنیدن کلمه، ضبط صدای خود مادر برای هر کلمه
- **حالت کودک:** ساختن همان کلمه با کاشی‌های رنگی بزرگ و بررسی خودکار جواب
  - سطح «ساده»: کلمه دیده می‌شود و فقط چند حرف روی صفحه است
  - سطح «شنیداری»: فقط صدا پخش می‌شود و همه‌ی حرف‌ها در دسترس‌اند
- امتیاز، ستاره، کنفتی و برچسب جایزه برای هر ۵۰ امتیاز؛ بدون امتیاز منفی و بدون زمان‌سنج
- طراحی موبایل‌محور، راست‌به‌چپ، با پشتیبانی از حالت تیره

## صدا

روی بسیاری از گوشی‌ها (از جمله کروم اندروید) صدای فارسی نصب نیست. برای همین بازی اول صدای ضبط‌شده‌ی شما را پخش می‌کند و فقط اگر ضبطی نبود از صدای ماشینی گوشی استفاده می‌کند.

برای ضبط: در حالت معلم حرف‌ها را انتخاب کنید، دکمه‌ی 🎙 را بزنید، کلمه را بگویید و دوباره دکمه را بزنید.

> میکروفون فقط روی آدرس **HTTPS** کار می‌کند (مثل GitHub Pages). اگر فایل را مستقیم از حافظه‌ی گوشی باز کنید، کروم اجازه‌ی میکروفون را نمی‌پرسد.

## اجرا

بازی یک فایل ساده است (`index.html`) و به سرور یا نصب چیزی نیاز ندارد.

**انتشار روی GitHub Pages**

1. فایل‌های این مخزن را در یک repository عمومی (Public) بگذارید
2. در Settings و بعد Pages گزینه‌ی Deploy from a branch را انتخاب کنید، شاخه‌ی `main` و پوشه‌ی `/ (root)` را بگذارید و Save بزنید
3. بعد از یکی دو دقیقه سایت در `https://USERNAME.github.io/REPO/` آماده است

**اجرای محلی:** فایل `index.html` را باز کنید (ضبط صدا در این حالت کار نمی‌کند).

## حریم خصوصی

همه‌چیز فقط در مرورگر خودتان می‌ماند. امتیازها و صدای ضبط‌شده در `localStorage` همان مرورگر و همان آدرس ذخیره می‌شوند، به هیچ سروری فرستاده نمی‌شوند و با پاک کردن اطلاعات سایت از بین می‌روند. بازی تبلیغ و لینک خارجی ندارد. تنها منبع بیرونی، فونت Vazirmatn از Google Fonts است و اگر بارگذاری نشود فونت جایگزین استفاده می‌شود.

## ساختار فنی

HTML و CSS و JavaScript خالص در یک فایل؛ بدون فریم‌ورک و بدون وابستگی. حروف و حرکت‌ها با یونیکد استاندارد نوشته شده‌اند (زبر `U+064E`، زیر `U+0650`، پیش `U+064F`) تا مرورگر خودش حروف را درست به هم بچسباند. جواب کودک به‌صورت آرایه‌ای از قطعه‌ها (حرف و حرکت) با جواب درست مقایسه می‌شود.

## ایده‌های مرحله‌ی بعد

- حروف ساکن، تشدید و تنوین
- کلمه‌های کامل همراه با تصویر
- بخش آشنایی با حرف و نمایش چهار شکل آن (جدا، اول، وسط، آخر)
- ذخیره‌ی صدای ضبط‌شده در IndexedDB به‌جای `localStorage` برای ظرفیت بیشتر

## English summary

**Colorful Alphabet** is a single-file web game that helps a first-grade child learn Persian letters and short syllables. A parent or teacher picks two letters (for example بَ + ه), the word is shown and spoken, and the child rebuilds it from large colored tiles to earn stars. Pure HTML, CSS and JavaScript, mobile-first, right-to-left, no backend. Because many phones have no Persian text-to-speech voice, parents can record their own voice for each word. Recording needs an HTTPS page such as GitHub Pages. All data stays in the browser's `localStorage`.
